# AfterFrame

> The film doesn't end at the credits.

AfterFrame is a full-stack MERN platform for cinematic discovery, regional popularity rankings, personal viewing diaries with half-star ratings, and community watch parties.

## Tech Stack
- **Frontend**: React, Vite, Vanilla CSS3
- **Backend**: Node.js, Express
- **Database**: MongoDB (Atlas)
- **External Data**: TMDB (The Movie Database)

## Project Structure
- `/client` - React & Vite frontend application
- `/server` - Node.js Express REST API backend
